# Phase 8B boundary after the living workday

Status: proposal; Phase 8A authorization does not approve this implementation.

First run four-human work-only playtests of the Phase 8A Windows build. Address unclear affordances, uninteresting decisions, excessive waiting, and unreliable transfers before adding deception. Current domain and networking checks establish material correctness, not fun.

The next bounded experiment can add one independently assigned nonlethal covert objective and one small innocent secret per player. Profession and assistant slot must remain independent of hidden status. Use the same parcel, stock handling, scrap and ordinary access routes; do not create a criminal-only animation, entrance or inventory. Provide two viable routes and ensure each also supports lawful errands.

Build evidence from the server-only item audit into deliberately limited receipts, service slips and collection manifests. Preserve role-targeted delivery. Extend the projection boundary with disclosed copies, attributed player claims and amendment history; never append the complete audit to a player snapshot. Validate all routes across the tested request seeds. Add a short end-of-day reconstruction discussion with no early removal; reserve final accusation rules for the later three-day MVP.

Before that work, decide how to hide remote object observations without breaking presentation replication, persist identity across reconnects, and recover from a host loss. Phase 8A recovers disconnected loads and assignment slots within a live host; it does not implement durable sessions, host migration or secret data. These concerns must not be solved by merely hiding UI fields.

Gates: four clients with no object duplication or private data leaks; all workers have two meaningful choices and independent useful activity; at least three of four human testers want another work-only shift; participants can describe a voluntary assist and explain how a work choice affected someone else. Record actual observations and dissent. Do not treat numeric gates as empirical guarantees.

Exclude combat, daily ejections, role catalogs, automatic guilt checks, free physics piles, large NPC simulation, new playable houses, a warehouse expansion and multi-day escalation from the first deception experiment. Any material networking replacement, destructive scene work or additional paid-generation budget needs a concrete review under the existing project constraints.
